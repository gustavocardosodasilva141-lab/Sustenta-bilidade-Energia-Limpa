# Energia Viva — Sustentabilidade e Energia Limpa

Site informativo sobre fontes de energia limpa, sustentabilidade e alternativas para um futuro energético mais consciente.

## Funcionalidades e páginas

- **Início:** apresentação do tema e destaques em carrossel.
- **Sobre o tema:** conteúdo introdutório.
- **Galeria:** apresentação de fontes de energia.
- **Dados:** informações e curiosidades.
- **Contato:** página de contato.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3

## Como visualizar

Abra o arquivo `index.html` em um navegador. O projeto utiliza o Bootstrap por CDN, então alguns recursos dependem de conexão com a internet.

## Estrutura principal

```text
.
├── index.html
├── sobre.html
├── galeria.html
├── dados.html
├── contato.html
├── style.css
├── script.js
└── image/
```
